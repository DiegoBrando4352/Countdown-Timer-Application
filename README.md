## 📝 Overview

An interactive countdown timer application featuring a 60-second countdown with Start, Stop, and Pause controls. The timer displays inside an apple graphic with dynamic CSS styling that changes when the timer reaches 15 seconds.

## 🚀 Live Demo

🔗 **[View Live Website](https://DiegoBrando4352.github.io/Countdown-Timer-Application/)**

## ⏱️ Timer Features

| Feature | Description |
|---------|-------------|
| **Countdown** | 60-second timer that counts down to zero |
| **Start** | Begins the countdown and enables Stop/Pause buttons |
| **Stop** | Resets the timer to 60 seconds and disables controls |
| **Pause/Resume** | Pauses the countdown; toggles to "Resume" when paused |

## 🎨 Dynamic Styling

- Timer text turns **yellow** on hover
- Timer text turns **red** when countdown reaches 15 seconds
- Red text has a rounded background to stand out from the apple image
- Buttons: Green (Start), Red (Stop), Orange (Pause)
- Black border appears on button hover

## 🔧 Button States

| Initial | After Start | After Stop |
|---------|-------------|------------|
| Start: ✅ Enabled | Start: ❌ Disabled | Start: ✅ Enabled |
| Stop: ❌ Disabled | Stop: ✅ Enabled | Stop: ❌ Disabled |
| Pause: ❌ Disabled | Pause: ✅ Enabled | Pause: ❌ Disabled |

## 🛠️ Technologies Used

- **HTML5** - Page structure with semantic elements
- **CSS3** - Flexbox, Google Fonts (Orbitron, Roboto), Hover effects, Dynamic styling
- **JavaScript** - setInterval, DOM manipulation, Event listeners, State management
